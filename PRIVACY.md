# Privacy

Auto Wallpaper Changer does not collect, sell, or transmit personal information.

The app makes outbound HTTPS requests only to:

- the configured Wallwidgy API and wallpaper storage hosts, to find and download wallpapers;
- GitHub's Releases API, when update checks are enabled.

Settings, wallpaper history, favorites, logs, thumbnails, and downloaded wallpaper files remain on the local computer under `%LOCALAPPDATA%\AutoWallpaperChanger`. Diagnostic archives are created only when the user explicitly selects **Export diagnostics**. They contain app settings, basic operating-system information, and app logs; they do not include wallpaper images or browser data.

Update checking, notifications, automatic rotation, and launch-at-login can be disabled in Settings.
